# Skills Index

This directory contains domain-specific operational guides used by agents in the
personal-library project.

## Active files (orchestrator-managed)

Updated by the Orchestrator at the end of each completed feature. Always current.

- `active-builder-task.md` — current builder task spec
- `active-qa-review.md` — current QA review checklist
- `active-orchestrator-session.md` — current orchestrator session guide

## Authoring rule

Each skill file should define:

- scope (what it covers and what it does not)
- inputs and outputs
- hard constraints
- common failure modes
- verification checklist
